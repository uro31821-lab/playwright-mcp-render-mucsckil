JH218 — Korean Life Hub / 쵸파·나미 분리 및 현재 카메라 화면 연결

적용 대상
- 앱 ID: com.koreanlifehub.bridge
- 현재 검증된 JH217 설치본에서만 데이터 보존 업데이트합니다.
- 기존 인증서를 사용하며 새 키를 만들지 않습니다. JH215 음성은 계속 중지입니다.

변경 사항
1. Korean Life Hub 아이콘은 허브 연결·설정 화면을 엽니다.
2. 쵸파·나미 스위치 아이콘은 독립 스위치 화면을 엽니다.
3. 오른쪽 스위치의 쵸파는 같은 공간에서 카메라를 엽니다.
4. GPT 화면 연결 중 최신 프레임 전달을 무거운 사물 인식과 분리했습니다.
5. 현재 오른쪽 화면·설정·목표 확인 후, 사용자 AUTO 입력이 있어야 대기합니다.
6. 목표 없음·다른 위치/크기·피사체 추적 소실·설정 변경·화면 이탈에는 자동촬영하지 않습니다.

실행 순서
1. 원래 설치에 사용한 Windows PC에서 ZIP 전체를 새 짧은 폴더에 풉니다.
2. 동일 휴대폰을 USB로 연결합니다.
3. 실행.cmd를 한 번 실행합니다. 기존 APK·원본 인증서·이번 APK 보안 검사를 먼저 합니다.
4. PC에 표시되는 업데이트 정보를 확인하고 YES를 입력합니다.
5. 완료 뒤 RESULT.txt로 설치 후 실제 APK 해시를 확인합니다.

불명확한 결과에서는 실행.cmd를 다시 누르지 말고 RESULT를 확인합니다.
기존 앱 삭제, 데이터 초기화, 서명키 업로드, 새 키 생성은 하지 않습니다.
기존 유효 빌드와 확인된 서명키 위치를 재사용합니다. PC에서 Gradle 빌드를 반복하지 않습니다.

설치 후 촬영 검증
참고 사진·자연어 스타일 → 실제 오른쪽 현재 화면 읽기 → 배율·색상·사진 종류·목표 위치/크기 적용 확인
→ 카메라 이동 안내 정확히 3줄 → 사용자가 자동촬영 버튼 누름 → 같은 목표 화살표 에이밍
→ 주인공·위치·크기·초점·안정 충족 시 한 장 저장 → 대기 해제.
배율/모드가 바뀌면 변경 후 새 프레임으로 다시 계획합니다. 피사체는 중앙에 고정하지 않습니다.

이 전달물의 코드·빌드·회귀검사와 실제 휴대폰 설치/촬영 성공은 별개입니다.
JH218의 허브/스위치 반복 진입, 실제 최신 프레임 수신, 목표 적용, 한 장 저장은 설치 후 확인해야 합니다.
Render 서버 변경/재배포와 JH215 음성 작업은 이 전달물에 포함하지 않았습니다.
