JH168 27단계 — Chrome 메뉴 완료 판정 업데이트

1. 이 ZIP을 Windows PC에서 [모두 압축 풀기] 합니다.
2. 기존 26단계 JH 앱이 설치된 휴대폰 한 대를 USB로 연결합니다.
3. 맨 위의 [실행.cmd]를 더블클릭합니다.
4. 완료 후 같은 폴더의 RESULT.txt를 이 대화에 올려주세요.
   다른 결과 경로가 표시되면 화면의 RESULT_PATH에 있는 RESULT.txt를 올려주세요.

이 파일은 확인된 27단계 APK를 기존 앱 위에 업데이트합니다.
APK를 다시 빌드하거나 새 서명키를 만들지 않습니다.
같은 27단계 APK가 이미 설치돼 있으면 다시 설치하지 않고 현재 상태를 확인합니다.
기존 RESULT.txt는 out/history 아래에 보존하고 이번 결과를 새 RESULT.txt에 기록합니다.
이전 설치 시도가 불명확하면 자동으로 반복 설치하지 않습니다.
설치 뒤 Chrome 메뉴의 실제 열림, JH 완료 판정, 서버 결과 수신을 이어서 확인합니다.

검증된 빌드: 시험 1,165개, 실패 0·오류 0·건너뜀 1개.
이 패키지 자체로 실기기 동작 확인이나 서버 배포가 완료된 것은 아닙니다.

27단계 보완: APK 자체 정보(패키지명과 버전)를 SDK 35 aapt와 이진 매니페스트로 이중 검증했습니다.
실행 시 동일한 해시의 서명 APK와 검증 영수증을 대조하며, PC SDK aapt의 문자열 출력에 의존하지 않습니다.
이전 차단 기록은 설치 0회였고, 기존 26단계 앱 삭제 없이 다시 실행해도 됩니다.
