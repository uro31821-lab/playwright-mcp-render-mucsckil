JH231 읽기 전용 상태 확인 점검

- Windows PowerShell 5.1용 구문과 UTF-8 BOM/CRLF를 확인한다.
- 실행.cmd는 ASCII/CRLF, 따옴표 경로와 DisableDelayedExpansion을 유지한다.
- 실행 시작 문구와 각 읽기 단계가 즉시 표시되며 출력 전체를 배열에 모아 종료 때까지 숨기지 않는다.
- 기존 업데이트 실행기·서명 도구·ADB·프로세스 종료 명령을 호출하지 않는다.
- 현재 JH231 실행의 원문 command line과 환경변수·암호·서명키 경로를 출력하지 않는다.
- 프로세스 관찰만으로 설치 완료를 주장하지 않는다.
- 원래 실행기가 계속 진행 중이면 intent 부재도 미실행 증거로 사용하지 않는다.
- 기존 RESULT와 install intent를 수정·삭제하지 않는다.
- 새 진단 결과는 CreateNew로 저장하고 기존 이름을 덮어쓰지 않는다.
- 실제 Windows 무해한 fixture 검사는 사용자 PC의 설치 성공을 의미하지 않는다.
