JH168 Mobile13 업데이트 — 압축 풀기 → 실행.cmd

1. 이전 JH 업데이트에 사용한 Windows PC에서 ZIP 전체 압축을 풉니다.
2. 원래 휴대폰 한 대를 USB로 연결하고, 필요한 USB 디버깅 승인만 휴대폰에서 직접 합니다.
3. 압축 해제 폴더의 실행.cmd를 한 번 더블클릭합니다.
4. 완료 후 생성된 RESULT.txt를 이 대화에 첨부합니다. 다른 위치에 저장되면 실행 창의 RESULT_PATH 위치를 사용합니다.

완성된 APK와 1,183개 단위검사 결과를 재사용하므로 앱을 다시 빌드하지 않습니다.
원래 PC의 기존 Android SDK/JDK17와 기존 debug.keystore만 사용합니다.
기존 앱과 인증서가 일치할 때만 앱 데이터를 유지하는 업데이트 설치를 한 번 수행합니다.
이전 설치본이 확인된 Stage27 APK와 다르면 덮어쓰지 않고 결과에 이유를 남깁니다.
앱 삭제, 데이터 초기화, 새 서명키 생성, UI 클릭, 기존 작업 재실행은 수행하지 않습니다.

다시 실행해도 확인된 서명 APK를 재사용합니다. 설치 결과가 불명확했던 경우에는 설치 상태를 읽고, 같은 업데이트를 자동 반복하지 않습니다.
이전 RESULT.txt는 logs 폴더에 보존되며 새 결과는 현재 실행 ID로 구분합니다.
로그와 결과에는 개인키, 비밀번호, 계정 화면, 원래 작업 본문을 기록하지 않습니다.

이 파일은 앱 업데이트만 수행합니다. 서버 반영과 휴대폰 13개 경로 검증은 RESULT 확인 후 같은 작업에서 이어갑니다.
Windows 합성 실행 검사와 주인님 PC의 실제 서명·설치 결과는 별도입니다.
