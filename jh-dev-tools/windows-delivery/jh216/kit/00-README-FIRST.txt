JH216 카메라·쵸파/나미 업데이트 FIX2 — APK 내부 파일 대소문자 비교 수정

JH215 음성 기능은 중지 상태이며 포함하지 않았습니다.
기존 JH214 서명 작업에 사용했던 Windows PC와 같은 휴대폰을 사용합니다.

1. ZIP 전체를 새 짧은 폴더(예: C:\JH216FIX2)에 압축 해제합니다.
2. 휴대폰을 USB로 연결하고 실행.cmd를 한 번 실행합니다.
3. 기존 인증서·앱 해시 검사가 통과하고 설치할 준비가 되면 PC에서 YES를 입력합니다.
4. 끝나면 RESULT.txt를 올려 주세요. 실제 촬영 검증은 설치 확인 뒤 진행합니다.

이미 검증한 APK를 사용하므로 PC에서 Gradle 빌드를 하지 않습니다. 기존 JH214의 앱 데이터는 유지합니다.
다른 버전/기기/해시이면 차단합니다. 실패·중단·결과 불명확 때 다시 실행하지 말고 현재 RESULT를 전달합니다.
키스토어·암호를 업로드하지 마세요. 기존 JAVA_HOME/Android SDK 35.0.0/ADB를 사용합니다.
기본 Android 키가 다르면 JH214에서 사용한 기존 JH 폴더를 제한된 범위에서 확인합니다. 원래 인증서와 일치하는 개인키만 사용하며, 성공한 위치는 PC 내부에만 기록합니다. 키를 새로 만들지 않습니다.
카메라가 열려도 자동촬영 대기는 켜지지 않습니다. 안내 3줄을 받고 사용자가 자동촬영 버튼을 눌러야 합니다.
기능 코드 1,457개 단위검사 통과를 재사용했지만 이번 APK의 서명·설치·실제 촬영은 PC/휴대폰 실행 전까지 미검증입니다.

이전 RESULT의 설치 시도는 0회였습니다. APK는 동일하며 FIX1의 서명키 검색 보완을 유지하고 APK 내부 파일 비교를 수정했습니다. 이전 폴더·RESULT는 보존하고 이번 ZIP을 새 폴더에 풉니다.

FIX1에서 원래 키를 찾았으나, 검사기가 APK 파일 이름의 대소문자를 구분하지 않아 멈췄습니다. FIX2는 정확한 파일 이름으로 비교하고 진짜 중복·내용 변경은 계속 차단합니다. 서명·설치는 아직 수행하지 않았습니다.
