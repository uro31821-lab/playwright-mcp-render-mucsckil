JH217 카비서 — 오른쪽 화면 유지 및 GPT 연결 상태 표시

JH216 설치가 확인된 원래 Windows PC와 휴대폰에서 사용합니다.
JH215 음성 기능은 중지 상태이며 포함하지 않았습니다.

1. ZIP 전체를 새 짧은 폴더(예: C:\JH217)에 압축 해제합니다.
2. 휴대폰을 USB로 연결하고 실행.cmd를 한 번 실행합니다.
3. 기존 인증서·현재 JH216 앱 해시 검사가 통과하면 PC에서 YES를 입력합니다.
4. 끝나면 RESULT.txt를 올려 주세요.

수정 내용
- 오른쪽 쵸파 스위치 화면에서 카메라를 열 때 같은 화면 안에서 전환합니다.
- GPT 연결 버튼에 켜짐/꺼짐 상태를 표시합니다. 쵸파로 시작하면 연결 켜짐입니다.
- 기존 자동촬영 순서와 사용자 버튼 입력 조건을 유지합니다.

검증된 새 APK를 동봉하므로 PC에서 Gradle 빌드를 반복하지 않습니다.
원래 인증서를 사용하며 현재 설치된 JH216의 정확한 해시를 확인합니다.
앱 삭제·데이터 초기화·새 서명키 생성은 하지 않습니다.
현재 APK의 서명·Defender 검사·USB 업데이트·설치 해시 확인은 이 실행에서 수행합니다.
다른 앱 해시이거나 실패·중단·결과 불명확이면 자동 재시도하지 않습니다.
이전 폴더와 RESULT.txt를 보존하고 이번 ZIP을 새 폴더에 풉니다.
키스토어와 비밀번호는 PC 내부에만 두며 업로드하지 마세요.

설치 후 확인
왼쪽 GPT + 오른쪽 비서 스위치에서 쵸파를 눌러 오른쪽에 카메라가 열리는지 확인합니다.
참고사진·스타일 → 현재 카메라 화면 확인 → 설정/구도 적용 → 안내 3줄 → 사용자가 자동촬영 버튼 → 대기 → 목표 일치 후 한 장 촬영 순서입니다.
실제 화면 배치·촬영 완료는 설치 후 확인할 항목이며 현재 통과했다고 주장하지 않습니다.
