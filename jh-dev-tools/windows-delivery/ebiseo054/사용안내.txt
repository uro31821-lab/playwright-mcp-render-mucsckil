이비서 0.5.4 — 음악 재생 순서와 관계없는 자동 EQ 시작

이비서를 먼저 켜 두거나, 음악을 듣다가 나중에 켤 수 있도록 수정한 기존 JH 업데이트 후보입니다.
GPT에서는 '이비서 시작', '이비서 중지'를 사용합니다.
시작하면 켜짐과 AUTO를 저장합니다. 음악이 없으면 기다리며 유튜브 뮤직을 자동으로 열지 않습니다.
현재 오디오 세션이 확인되면 EQ 적용을 시도하고, 실제 엔진 확인 후에만 적용 중으로 표시합니다.
곡 정보만으로 실제 소리 처리 연결을 만들지 않습니다.
중지하면 EQ만 끄고 음악 재생은 유지합니다.

실행 전 동봉된 전달 검증 결과를 확인합니다.
Windows 실행 검증·전달 프로필·기기 설치 여부는 각각의 검증 결과를 기준으로 합니다.

최종 검증 후 실행 방법
1. ZIP을 C:\JHEQ 같은 짧은 경로에 완전히 풉니다.
2. 원래 JH 서명키가 있는 Windows PC에 잠금 해제된 휴대폰 한 대를 USB로 연결합니다.
3. 실행.cmd를 한 번 실행합니다.
4. 기존 APK·현재 앱·원본 인증서 확인이 통과하면 마지막 질문에 Y를 한 번 입력합니다.
5. 표시된 RESULT_PATH의 RESULT.txt를 GPT에 올립니다.

PC에서는 이미 검증한 APK의 서명과 업데이트만 합니다. Gradle 빌드는 실행하지 않습니다.
원본 인증서만 허용하며 기존 앱과 데이터를 보존합니다. 새 키는 생성하지 않습니다.
기존 키가 검색되지 않으면 기존 PC의 키 위치를 확인해야 합니다.
기본 Android 키 비밀번호 외의 비밀번호는 PC의 로컬 환경 설정으로만 전달할 수 있습니다.
개인키·비밀번호를 GPT에 올리거나 이 폴더에 복사하지 마세요.

UNKNOWN이나 BLOCKED가 나오면 자동 재실행하지 말고 현재 RESULT.txt를 전달하세요.
한 번 시도한 설치는 영구 시도 기록으로 보호합니다.
설치 결과가 같은 APK 해시로 이미 확인되면 설치를 생략합니다.
결과와 서명된 APK는 실행별 폴더와 PC 사용자 폴더에 보존합니다.
APK 설치 확인, 운영 서버의 음향 도구 연결, 실제 YouTube Music 음향 작동 확인은 각각 별도 단계입니다.
