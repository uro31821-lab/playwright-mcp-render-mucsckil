# JH 카비서·편비서 협력 — 왼쪽 GPT 촬영 예시

**사용자 2026-11-21 최종 확정:** 핵심은 '현재 참고사진 + 분위기 입력 → 편비서 자동 협력 → ChatGPT 기본 이미지 생성 → 왼쪽 GPT 대화창에 촬영 구도 예시 한 장과 쉬운 안내 세 줄'. 중지한 기능은 '왼쪽 예시사진 파일을 오른쪽 카비서로 자동 전송' 하나뿐이다.

## 조건과 역할
- 주담당은 카비서(camera), 예시사진 제작 협력은 편비서(photo).
- 현재 대화에 실제로 올라온 REFERENCE 사진과 명확한 촬영 요청, 분위기가 있을 때 **사용자에게 추가 버튼이나 별도 비서 선택을 요구하지 않고** 이 협력을 시작한다.
- 촬영 사진의 참고와 기존 완성 사진 자체의 직접 편집은 엄격히 구분한다. 기존 `routeShootingTurn` 및 `verifyShootingRoute`로 촬영임이 확인되면 **기존 'edit_existing' 사진 편집 실행으로 오인하지 않고** 구도 시안 협력만 수행한다. 라우팅 불확실·인용·부정·설명·개발 요청에는 자동 이미지 생성을 시작하지 않는다.
- 참고사진이 여러 장이면 현재 확인된 주된 참고사진 한 장을 사용하고, 대상을 정할 수 없을 때만 한 가지 확인한다. 이전 대화의 사진을 대신 사용하지 않는다.

## 왼쪽 GPT 실제 출력
1. 현재 사용자의 참고사진을 확인한다. **주인공·물체 수·배경·정체성**을 최대한 보존하며 원하는 분위기를 반영한다.
2. ChatGPT가 현재 제공하는 내장 `image_gen` 도구로 **시점·거리·높이·사선 45도·회전·기울기·줌** 등을 조절한 *근사 구도 예시사진 1장*을 실제 생성하고 왼쪽 GPT 대화창에 보여준다. 사진 속 물체를 옮기거나 추가·삭제하지 않는다. 물리적으로 정확히 촬영 가능한 구도를 보장한다고 말하지 않는다.
3. 같은 왼쪽 GPT에서 행동 중심의 **아주 쉬운 촬영 안내 정확히 3줄**을 보여준다. 각 줄은 짧게: "조금 가까이 가요." / "왼쪽 옆으로 가요." / "폰을 살짝 기울여요." 필요한 경우 다양한 카메라 방향과 회전을 허용하되 제품·조명·배경을 옮기라고 하지 않는다.
4. **실제 이미지 생성 도구 결과가 보여야만 완료**라고 표시한다. 실행 지시나 계획만 만들고 생성 성공이라 주장하지 않는다. 같은 사용자 요청에서 자동 재생성하지 않는다.

## 변경·작동 금지
- **왼쪽 GPT 생성 이미지를 오른쪽 카비서/Secure56/Android로 자동 전송·다운로드·스테이징하지 않는다.** 사용자에게 복사·붙여넣기를 시키지도 않는다.
- 별도 유료 이미지 REST API, API 키 발급, 외부 유료 서비스로 자동 전환하지 않는다.
- 카비서 오른쪽 앱의 줌/모드 설정·3×3 격자·수평계·사용자 직접 AUTO·1장 촬영·저장은 **기존 동작을 유지**하며 이 협력에서 원격 AUTO나 셔터를 실행하지 않는다.
- 오른쪽 카비서가 실제로 사진을 받았거나 카메라 설정이 적용됐다고 표시하지 않는다.

## 운영 연결
기존 JH `jh-assistant-hub`는 주담당 카비서를 유지하면서 이 좁은 촬영 예시 제작을 편비서의 협력 기능으로 배정한다. `jh-pyeonbiseo`의 기존 완료 사진 `edit_existing` 제한은 유지한다. 설명과 촬영 구도 예시의 생성 요청은 구분한다. 호스트에서 실제 ChatGPT 이미지 생성 결과와 왼쪽 표시가 확인되지 않으면 생성 기능은 미확정이다.
