## 변경 절대 금지

- JH230 설치된 Android 및 그 소스, 원본 인증서/키, 데이터, Secure56 및 서버 라이브 배포
- 기존 격자·수평계·AUTO 직접 터치, AUTO 이후 AF/AE/AWB·흔들림, 프리즈·1장 촬영·저장·재조회
- 기존 편비서의 일반 `edit_existing` 편집 기능 및 사용자 선택 메뉴
- 촬영 사진을 사용자가 **직접** 왼쪽 GPT에 다시 올린 뒤 분석·재지도하는 기존 GPT 기능(15번), 자동 업로드 금지
- 구형 실선·점선·실시간 피사체 추적 기능 되살리기 금지
- GPT의 카메라 **실시간** 프레임 수신을 구도 결정의 필수 단계로 삼지 않음
- 새 유료 이미지 모델·외부 API·카메라 JPEG를 오른쪽으로 전송하는 기능 없음

## 실행 역할

1. 사용자가 현재 촬영 참고사진과 분위기를 전달한 촬영 요청에만 GPT 카비서 경로 진입한다. 기능 개발·설명, 단순 사진 평가/추천, 기존 사진 직접 편집은 자동 예시 생성을 시작하지 않는다.
2. GPT가 **현재 업로드한 참고사진**(다른 방의 실제 이미지는 불가)·검증된 최신 비공개 취향만 참고하여 사실과 추정을 구분하고 구도를 결정한다. 원본 보존과 현실 재현성 우선.
3. GPT가 **기본 image_gen**을 실제 호출해 예시사진 한 장을 LEFT ChatGPT에 띄운다. 모듈 텍스트만 생성해서 이미지가 나왔다고 주장하지 않는다.
4. GPT가 표시된 예시를 확인한 뒤 정확히 쉬운 3줄을 LEFT에 제시한다.
5. 기존 우측 카비서의 인증된 MCP 설정·줌 도구를 **값만** 한 번 호출, 현재 CameraX 상태를 읽어보고 실제 적용한 항목만 성공으로 보고한다. 오른쪽 사진 자동 전송 없음. 좌측 실패를 오른쪽 성공으로 덮지 않는다.
6. 사용자가 구도를 직접 맞춰 네이티브 AUTO를 누를 때까지 촬영 트리거 없음.

## 검증과 완료 표시

- Android JH230 APK는 이미 설치·서명 증거가 확인됨. 새 호스트 연계만 변경할 때 **신규 APK 재빌드·서명·설치 불필요**, 기존 서명본 그대로 재사용.
- Node 정책/호스트 콜백 모의시험 PASS와 실제 이미지 도구/카메라 E2E PASS를 엄격히 분리.
- 사용자 업로드 촬영용 참조사진이 없는 이번 개발 요청만으로 image_gen을 실행하거나 E2E PASS라고 표시하지 않는다.
- 연계 도구가 지원되지 않으면 `UNBOUND`, 시도 확인이 불명확하면 `UNKNOWN_NO_AUTO_RETRY`, 실제 사용자에게 표시되면 `VERIFIED_LEFT_VISIBLE`만 사용할 것.
- 다른 방에서 “인계비서 카비서 7개 보강표”로 조회할 때 이 문서의 최신 판본과 JH_DEV_MASTER의 연결 ID를 읽고 **정확히 이 7개 범위만** 작업한다.
