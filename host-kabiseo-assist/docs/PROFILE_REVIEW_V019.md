## 실제 진전
서버 실행과 무관하게 진행할 수 있는 화면 식별자료 검토기를 작성했습니다. 카메라의 두 번의 서로 다른 열림, 대화창과 사진 확인창의 대조자료를 같은 앱/버전/서명/화면 구성 기준으로 비교합니다. 식별표시 중복, 부족한 관찰, 가려진 화면, 입력/암호 필드, 다른 화면에서 같은 카메라 표시가 재사용되는 경우를 거부합니다. 접힌 화면과 펼친 화면 자료를 임의로 합치지 않습니다.

결과는 항상 미승인 draft이며 자동 등록하지 않습니다. 실제 기존 CameraSurfacePolicy에 이 draft를 넣으면 거부되는 것까지 시험했습니다. 표본의 label/identity 문자열은 이 검토기가 인증하지 않습니다. 가상 자료 통과를 실기기 관찰이나 사용자 승인으로 바꾸지 않습니다.
