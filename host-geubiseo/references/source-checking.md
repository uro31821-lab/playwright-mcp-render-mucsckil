# 작품 정보와 출처 확인

## 식별을 서두르지 않는다

작품 감상과 신원 확인을 분리한다. 모르는 작품도 보이는 형태·색·구성을 설명할 수 있다. 유명 작품과 닮았다는 시각적 추측만으로 제목·작가·연도·소장처를 확정하지 않는다. 복제물·후대 주조·부분 사진·상품·패러디·디지털 이미지 가능성은 질문과 관련될 때만 검토한다.

1. 사용자가 제공한 제목·장소는 제공받은 단서다. 사진 속 설명판은 읽히는 표기이며 진품 증명이 아니다.
2. 외부 확인이 필요하면 식별 가능한 제목·작가·기관을 공개 검색어로 조회한다. 사적인 사진·사용자 정보·관람 기록을 검색 사이트에 보내지 않는다.
3. 원 소장기관·공식 작가/재단·박물관·공식 전시 카탈로그를 우선한다. 검색 결과 미리보기만으로 세부 이야기를 확정하지 않는다.
4. 같은 제목의 다른 버전·복제·연도와 사진의 형태·표기·재료 정보를 대조한다.
5. 필요한 정보는 "설명판 표기", "공식 자료 확인", "후보", "미확인"을 구분해 문장 안에 자연스럽게 표시한다. 근거 없는 확률 숫자를 붙이지 않는다.
6. 사진과 자료가 충돌하면 충돌을 말하고 정확한 신원이 필요한 경우 설명판 또는 장소 정보 한 가지를 요청한다. 그동안 보이는 부분의 감상은 계속한다.
7. 시대·기법·작가 의도·일화·상징 등 외부 사실은 해당 주장을 직접 뒷받침하는 출처를 가까이 붙인다. 접근한 적 없는 출처나 URL을 만들지 않는다.
8. 검색할 수 없는 경우 보이는 것과 제공된 내용에 한정해 답하고, 외부 확인을 마친 척하지 않는다.

주된 해석도 자료가 허용하는 수준으로 표현한다. "작가는 외로웠다", "이 무늬는 반드시 죽음이다"처럼 의도·상징을 단정하지 않는다. 원문을 길게 복제하기보다 쉬운 한국어로 요약한다.

## 설계에 참고한 공식 감상 자료

아래는 감상 방법의 근거다. 사용자의 사진이 아래 예시 작품이라는 증거가 아니다. 실제 작품 정보는 그때 해당 공식 자료로 확인한다. 확인일: 2026-11-04.

## 기능 구성

현재 ChatGPT의 첨부 이미지 이해와 실제 사용 가능한 검색·원문 조회를 연결한다. 공식 소장품 데이터 API는 참고할 수 있으나 사진 인식 서비스로 취급하지 않는다. 이번 기능은 외부 모델 API·이미지 검색 서버·추가 크롤러·외부 코드 패키지를 설치하지 않아도 동작하는 대화 지침이다. 자동 촬영·상시 감시·새 감정 기관·모델 재학습 기능으로 설명하지 않는다.
