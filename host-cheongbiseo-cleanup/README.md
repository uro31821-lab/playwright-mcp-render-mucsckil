# 청비서 — JH Space cleanup

청비서는 JH 내부의 수명주기 정리 기능이다.

## 확정 규칙

- 사용자가 **실행 명령을 했을 때만** 동작한다. 예약/백그라운드 자동 실행은 하지 않는다.
- 현재 Space의 **이미지 파일은 생성/저장 후 12시간 이상**이면 삭제 대상이다.
- 현재 Space의 **비이미지 파일은 생성/저장 후 14일 이상**이면 삭제 대상이다.
- 이미지에는 12시간 규칙이 우선한다.
- 폴더는 삭제하지 않는다.
- 먼저 dry-run으로 대상 수를 계산하고, 그 다음 실제 삭제하고, 같은 조건으로 재조회해 검증한다.
- 아직 보존기간이 지나지 않은 파일은 그대로 둔다.
- 프로젝트 첨부/지식처럼 호스트가 삭제할 수 없는 항목은 성공으로 가장하지 않고 blocked로 보고한다.
- connector-synced 파일은 청비서가 원본을 삭제하지 않는다.
- 일시적 서버 오류는 안정적인 library_file_id로 1회만 재시도한다.
- 결과 기본 출력은 대상/삭제/차단/실패/남은 만료대상 개수다.

## 실행 구조

사용자 → ChatGPT/JH → `life_cheongbiseo_policy` → Host Files → 삭제 → 재조회 검증 → 결과

JH 서버는 ChatGPT Project 파일 저장소를 직접 삭제하지 않는다. JH는 정책을 제공하고, 실제 삭제는 현재 대화 호스트가 가진 Files 권한으로 수행한다.
