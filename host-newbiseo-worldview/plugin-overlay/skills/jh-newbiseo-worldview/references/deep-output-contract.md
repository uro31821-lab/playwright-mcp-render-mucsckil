# 뉴비서 심층 사건 해부 계약

## 심층형의 목적

기본 뉴스토리가 사건의 흐름과 현재 상태를 이해시키는 기능이라면, 심층형은 그 사건이 **왜 그렇게 움직였는지, 누가 어떤 이해관계를 갖는지, 다른 설명은 가능한지, 다음에 무엇이 확인되면 관점을 바꿔야 하는지**를 해부한다.

심층형은 더 긴 요약이 아니다. 다음의 중간 추론층을 검증한다.

`확인된 사실 → 인과 메커니즘 → 이해관계·충돌 → 대안 해석 → 유사사례 전이 위험 → 개인 적용`

## 인과사슬

각 연결은 다음을 가져야 한다.

- 원인으로 사용한 사실 ID
- 실제로 작동했다고 보는 메커니즘
- 결과로 연결한 사실 ID
- 확신 수준: high / medium / low / unknown
- 존재하는 경우 반대 근거 ID

시간적으로 먼저 일어났다는 이유만으로 원인으로 처리하지 않는다. 같은 사실을 한 연결의 원인과 결과에 동시에 넣지 않는다.

## 이해관계 지도

최소 2개의 주체를 본다. 각 주체마다:

- 역할
- 목표
- 실제 영향력
- 얻는 것
- 잃는 것
- 떠안는 위험
- 근거 사실

을 구분한다. 확인되지 않은 숨은 동기는 쓰지 않는다.

## 핵심 충돌

서로 동시에 만족시키기 어려운 목표가 있을 때만 작성한다. 충돌에 관련된 이해관계자와 근거 사실을 연결한다. 단순 찬반 요약이 아니라 왜 타협이 어려운지 설명한다.

## 세 개의 시계

항상 다음을 분리한다.

1. 미디어의 시계 — 관심의 상승·활성·감소·침묵·재부상
2. 제도의 시계 — 제안·검토·조사·재판·결정·집행·정체·종료
3. 현실 변화의 시계 — 미착수·초기 변화·가시화·정착·후퇴

뉴스가 조용한 것과 사건이 끝난 것을 같은 뜻으로 취급하지 않는다.

## 대안 해석

최소 하나의 경쟁 설명을 둔다. 각 설명에는:

- 지지하는 사실
- 약화하는 사실
- 확신 수준
- 무엇이 확인되면 생각을 바꿀지

가 있어야 한다. 형식적인 양비론은 허용하지 않는다.

## 유사사례 검토

기본형에서 선택한 모든 유사사례를 다음 세 항목으로 다시 평가한다.

- 구조 일치
- 환경 일치
- 과거 결말을 현재에 옮길 위험

구조가 닮아도 결말 전이 위험이 높을 수 있다. 이 평가는 예측 확률이 아니다.

## 반사실

실제로 일어나지 않은 조건을 바꿔 핵심 원인을 점검한다. 사실이나 미래 예측으로 표현하지 않는다. 근거가 약하면 생략한다.

## 판단 신호

현재 답변 안에서만 제시한다. 알림이나 지속 추적을 만들지 않는다. 각 신호에는:

- 무엇을 볼지
- 나타나면 무엇을 뜻하는지
- 나타나지 않으면 무엇을 뜻하는지
- 어느 시기인지
- 어떤 종류의 자료로 확인할지

가 있어야 한다.

## 개인 영감 품질검사

기본형의 모든 영감을 다시 검토한다.

- direct / adjacent는 실제 사용자 맥락 라벨을 최소 하나 참조해야 한다.
- 사용자 맥락이 없으면 general만 허용한다.
- 채택한 아이디어는 작은 행동과 확인 기준을 가져야 한다.
- 제외한 아이디어에는 행동을 붙이지 않는다.
- 부담과 위험을 low / medium / high로 표시한다.
- 최소 하나의 아이디어만 채택하면 된다. 억지로 모두 살리지 않는다.

## 상태·실행 경계

- 심층 분석은 사실 조사 이후의 읽기·해석 단계다.
- 모니터링, 백그라운드 추적, 자동 알림 없음.
- 자동 저장 없음.
- 휴대폰·메일·배포 실행 권한 없음.
- 명시적 저장 요청이 있을 때만 기존 에비서/JHAI 저장 경로를 사용한다.
