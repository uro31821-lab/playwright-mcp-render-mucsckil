# JH 뉴비서 — World View Engine

뉴비서는 팩트체크 도구의 다른 이름이 아니다. 공개 자료로 사건의 시작부터 현재까지를 확인한 뒤, 반복되는 사회·경제·행동 패턴과 과거의 구조적 유사사례를 연결하고, 사용자에게 실제로 의미 있는 생각과 아이디어를 만드는 **세상을 보는 관점 기능**이다.

`worldview.mjs`는 검색이나 모델 추론을 대신하지 않는다. 호스트가 조사·작성한 자료를 받아 사실, 보도·주장, 해석, 비교, 개인 영감을 분리하고, 출처 연결·개수 제한·무추적·무자동저장 경계를 검증한다. `renderKorean()`은 이 대화에서 확정한 뉴스토리 폼의 결정적 초안을 만든다. 실제 답변에서는 내부 source ID를 현재 웹 인용으로 바꿔야 한다.

기본 출력은 `그때 무슨 일이 → 그 후 → 그래서 지금은 → 왜 다시 뉴스가 됐나(해당 시) → 반복되는 패턴 → 과거 유사사례 → 이 뉴스에서 건질 것 → 나에게 한 문장`이다. 유사사례와 영감은 억지로 채우지 않는다. 영감은 경제·투자·병원/경영·일·인간관계·정신/삶·AI 아이디어 중 관련 있는 최대 3개만 쓴다.

이 기능은 계속 추적, 알림, 백그라운드 수집, 자동 저장을 만들지 않는다. 사용자가 명시적으로 저장을 요청할 때만 기존 에비서/JHAI Second Brain 경로를 사용한다. 기존 Evidence Research는 사실 확인을 돕는 하부 기능일 수 있지만, 뉴비서의 목적은 사실 검증 자체가 아니라 사건을 통해 세상을 보는 관점을 넓히는 것이다.

검사:

```bash
node host-newbiseo-worldview/sync-overlay.mjs
node --test host-newbiseo-worldview/*.test.mjs
```
