# JH 뉴비서 — World View Engine

뉴비서는 팩트체크 도구의 다른 이름이 아니다. 공개 자료로 사건의 시작부터 현재까지를 확인한 뒤, 반복되는 사회·경제·행동 패턴과 과거의 구조적 유사사례를 연결하고, 사용자에게 실제로 의미 있는 생각과 아이디어를 만드는 **세상을 보는 관점 기능**이다.

뉴비서 출력이 시작되면 제목 앞의 **🏴‍☠️ 해골기**로 뉴비서가 작동 중임을 표시한다.

## 두 단계

- **기본 뉴스토리:** `그때 → 그 후 → 지금 → 반복 패턴 → 과거 유사사례 → 나에게 건질 것 → 한 문장`
  - 과거 유사사례와 나에게 건질 아이디어는 기본 고정 항목이다.
  - 직접 비교할 사례가 없더라도 유사사례 항목을 유지하고 그 사실을 명시한다.
  - 나에게 건질 아이디어는 근거 있는 최소 1개, 최대 3개와 작은 행동을 포함한다.
- **심층 뉴스토리:** 기본형 전체를 유지한 뒤 인과사슬, 이해관계 지도, 핵심 충돌, 미디어·제도·현실의 세 개 시계, 가장 강한 반대 해석, 유사사례 전이 위험, 반사실, 판단 신호, 개인 영감 품질검사를 추가한다.

`worldview.mjs`는 기본 보고서의 사실·보도·주장·해석·비교·개인 영감을 분리한다. 유사사례 배열이 비어 있어도 기본 출력의 유사사례 제목과 정직한 무사례 안내를 렌더링한다. `deep-worldview.mjs`는 검증된 기본 보고서 위에서 인과 해석과 이해관계, 경쟁 설명, 판단 기준을 제한된 구조로 검증한다. 두 런타임 모두 검색이나 모델 추론을 대신하지 않으며, 계속 추적·알림·백그라운드 수집·자동 저장·기기 실행을 수행하지 않는다.

실제 답변에서는 내부 source ID를 현재 웹 인용으로 교체한다. 영감은 경제·투자·병원/경영·일·인간관계·정신/삶·AI 아이디어 중 실제로 관련 있는 최소 1개, 최대 3개만 사용하고, 심층 품질검사에서 부담·위험·작은 행동·확인 기준을 검토한다.

## 재현 가능한 소스

기본 런타임 `worldview.mjs`는 직접 보관하고, 심층 런타임과 심층 회귀검사는 `source-parts/*.b64.NNN`으로 보관한다. 동기화 스크립트가 소스를 읽거나 재조립하고 배포본의 고정 SHA-256과 대조한 뒤 플러그인 오버레이를 생성한다.

- `worldview.mjs`: `1b17598e43f09923b6ea84e8520449a657e77ea4c6adbe690268ef9efd2d0036`
- `deep-worldview.mjs`: `d63ded87aeb74e4190c50ddf8ece7ad93e215584ae82eee73f97548f5ba56475`

## 검사

```bash
node host-newbiseo-worldview/sync-overlay.mjs
node --test host-newbiseo-worldview/*.test.mjs
```

이 기능은 JH Secure Live 개인 플러그인의 호스트 스킬이다. Android APK, Render 서버, MCP 실행 권한은 변경하지 않는다. 사용자가 명시적으로 저장을 요청할 때만 기존 에비서/JHAI Second Brain 경로를 사용한다.
