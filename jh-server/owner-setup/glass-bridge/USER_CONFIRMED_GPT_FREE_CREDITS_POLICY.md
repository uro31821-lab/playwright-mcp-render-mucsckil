# JH 안비서 — GPT API 무료 지급 크레딧만 사용 (2026-11-11 사용자 재확정)

## 우선순위 — 사용자 확정 규칙
1. **목표 AI 엔진은 GPT API.** 독립 휴대전화 앱/JH에서 안경 카메라 사진과 질문을 처리할 때 GPT 모델을 우선 사용한다. ChatGPT 앱을 열어두거나 Meta AI를 기본 응답 엔진으로 강제하지 않는다.
2. **비용은 기존 ChatGPT 구독료 외 추가 0원.** 사용자 계정에 실제 지급된 **무료 API 크레딧(금액 기준)** 내에서만 GPT API를 호출한다. API 토큰(token)은 청구 단위가 아니라 모델 처리량 단위이며, '200 크레딧'은 정확한 단위와 무료 잔액 증거를 확인해야 한다.
3. **무료 크레딧이 없거나 식별/잔액/만료/실시간 과금 상태를 검증하지 못하면 GPT API 호출 자체를 차단.** 유료 결제로 넘어가는 자동 폴백, 재충전, 유료 API 호출은 금지한다.
4. **자동충전 OFF + 기존 결제/유료잔액 사용 금지.** '자동충전 OFF'가 기록상 확인되었어도 운영 시 최신 계정 설정을 다시 읽어야 한다. 앱 로그/버전 관리에 API Key, 결제정보, 원본 환자 사진을 남기지 않는다.
5. 실제 무료 잔액이 확인되면 사용 가능한 한도 이하에서만 요청한다. 각 요청의 모델, 최대 입력 이미지 수, 최대 출력 토큰, 사용자 승인된 총액 상한과 사용량 기록을 검사하고 누적 추정/확정 지출이 무료 잔액의 보수적 안전 여유에 도달하면 **시작 전에 거부**. 무료·유료 크레딧 사용 순서가 명확히 검증되지 않으면 호출 금지. OpenAI의 지연 청구/처리량 변동 때문에 **앱 내부 소프트웨어 예산 검사만으로 '0원 보장'이라고 주장할 수 없다**. 실제 계정/청구 정책으로 유료 과금을 원천 차단할 수 있음을 확인해야 한다.
6. 크레딧 소진 시 사용자는 '무료분 소진, GPT 분석 중지'라는 음성 응답/명확한 상태를 받는다. 원하지 않은 로컬 AI 자동 전환이나 음성 없는 무한 대기는 금지한다. 오프라인 모델은 **사용자가 따로 선택한 경우에만 대안**으로 검토한다.

## 이전에 공유된 수치 (현재 잔액이 아님)
- 과거 계정 화면에 대해 assistant가 **무료 API 혜택 월 최대 $200**, 첫 사용 가능액 **약 $190**, 다음 지급 예정일 **2026-12-09**, **자동충전 꺼짐**이라고 보고했다.
- 이는 그때의 화면/설명에서 유래한 **과거 보고**일 뿐 이번 작업에서 계정 API 청구 내역을 실제 재조회한 것이 아니다. 실제 지급/만료/과금 순서, 현재 잔액, 이 정책의 적용 여부는 별도 검증 전까지 미확인.
- ChatGPT Pro 구독과 OpenAI API 청구는 별개. 이 프로젝트에서는 개인의 무료 지급분이 실제 API에 연결되어 있다고 최신 계정 증거로 확인되기 전까지 GPT API 호출을 시작하지 않는다.

## 코드 및 출시 게이트 (미구현)
- OpenAI API 연동 구현: **NOT DONE**
- 무료 크레딧만 식별한 신뢰 가능한 계정 잔액/만료 readback: **NOT DONE**
- 자동충전/유료차감 방지의 계정 수준 차단 확인: **NOT DONE**
- 요청 예산 계산·잔액 예약·실패 시 fail-closed 안전정지: **NOT DONE**
- 실제 안경 → 카메라 → GPT API → JH 라우팅 → 안경 TTS E2E: **NOT DONE**
- 지금까지의 GitHub CI는 Kotlin DAT Voice/Speech/TTS와 서버 모의 인증 검증. 유료·무료 API 호출은 한 번도 실행하지 않았다.

## 변경된 설계 우선순위
`안경 음성 입력` → `사용자 지시 1회 카메라 캡처` → `JH Secure56 개인/기기 확인` → `실시간 무료 API 크레딧 검증 + 유료 차감 불가능 상태 검증` → `GPT API 사진·텍스트 분석` → `JH 전문비서 라우팅` → `안경 한국어 TTS`.

**기존 문서의 'offline/local vision is default' 표현은 이 사용자 확정에 따라 철회.** 무료 OpenAI API가 안 되면 실행 중단하고 상태를 알리며, 로컬 모델로 자동 바꾸지 않는다.
