## 신뢰 조건
1. Google/일반 웹 검색, 업체 소개, 영화 상영 시간표, 가격 목록은 **실시간 빈자리 증거가 아님**.
2. JH 호스트가 직접 호출한 신뢰 공급자의 **실시간 재고 API** 결과만 검증 근거.
3. 출처·조회시간(최대 2분)·날짜·시간·인원·동일 업체/지점/공연/진료과·등록 공식 도메인을 일치시킴.
4. 검색 후보 선택 시 동일 슬롯을 다시 조회. 사라졌거나 조회 실패한 자리는 진행 중지.
5. ‘조회 시점 예약 가능’은 예약 확정/좌석 보유/결제 완료가 아님.
6. 결제·송금·발권 및 개인정보 송신 없음. `protocol_version=1.0`, `command_id/generation/plan_revision` 호스트 권한 유지.

## 표시 상태
- `LIVE_OPTIONS_FOUND`: 신뢰 API에서 일치하는 슬롯을 확인한 시점에 한해 표시.
- `NO_CONFIRMED_AVAILABLE_SLOTS`: 조회한 제공자 기준 해당 조건 일치 슬롯이 없음. 지역 전체 매진이라는 의미 아님.
- `NO_LIVE_PROVIDER`: 이 업체/유형에 실시간 조회 경로 없음.
- `LIVE_QUERY_NOT_CONFIRMED`: 호출 실패·응답 오래됨·구조 불일치. 매진으로 표시하면 안 됨.
- `SLOT_NO_LONGER_VERIFIED`: 선택 전 재조회 시 동일 슬롯 확인 불가.
