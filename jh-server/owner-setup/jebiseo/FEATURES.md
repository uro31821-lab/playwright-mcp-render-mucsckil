# 제비서 기능과 완료 기준

갱신일: 2026-11-06 (KST).

## 핵심 자동 동작

최신 요청은 **요청문 선택(드래그와 같은 글 선택) → ‘Gemini에게 물어보기’ 클릭 → Gemini 실행 클릭**이다. 세 동작을 사용자가 하도록 안내하는 것만으로 구현 완료로 처리하지 않는다. 후보 기본 모드는 `AUTO_TEXT_SELECTION`이며 휴대폰의 왼쪽 GPT / 오른쪽 Gemini를 전제로 한다.

| 단계 | 구현 경로 | 성공 판단 |
| --- | --- | --- |
| 글 선택 | 새 Android native 전용 실행기, 지원되는 선택 API | 정확한 원문과 실제 선택 시작·끝 범위 확인 |
| Gemini로 보내기 | 출처가 확인된 실제 선택 메뉴 클릭 | 오른쪽 Gemini의 입력 초안과 보낸 문장 일치 |
| Gemini 실행 | 기존 Gemini 검토·정확한 로컬 승인·실제 버튼 클릭 | 실제 제출 관찰. 분석·앱 변경·영상 완료와 구별 |

왼쪽 전체 조작 권한을 열거나 직접 Intent·재입력으로 선택 메뉴를 대체하지 않는다. 접근성 선택 정보가 없거나 메뉴 귀속·오른쪽 배치·초안·전송 대상을 확인하지 못하면 그 단계에서 중단한다. 클릭 후 결과가 불명확하면 재전송하지 않는다.

## 세 가지 기능

| 기능 | 전달 대상 | 결과 |
| --- | --- | --- |
| 삼성 앱·기기 | 현재 사용자가 요청한 대상·동작·필요 내용. 일정·노트·계산기·알람·연결 기기는 예시 | Gemini가 실제 지원·연결하는 환경에서 실행하고 결과 확인 |
| 유튜브 분석 | 정확한 영상 링크와 분석 질문 | Gemini 분석 뒤 사용자가 실제 결과를 선택·공유해 GPT에서 이어가기 |
| 영상 생성 | 제작 프롬프트. 기존 구독 포함 범위와 추가 결제 없음 | Gemini에서 생성 상태·영상 확인 |

텍스트 전달 성공만으로 모든 삼성 기기 제어를 지원한다고 판단하지 않는다. 영상 생성 도구·계정 한도도 별도로 확인한다. 자동 결과 회수·영상 export는 완성되지 않았다. 유튜브 결과의 GPT 복귀 요구는 수동 공유 경로로 보존한다.

## 사용자 경험

호스트는 보낼 문장을 현재 GPT 화면에 한 번 표시한 뒤 같은 task의 실행기를 시작한다. 세 단계는 원 서버와 Android가 순서대로 수행한다. 기존 휴대폰의 대상별 승인이 반환되면 해당 승인을 처리하고 같은 작업을 재개한다. 자동화가 없을 때 사용자에게 드래그·클릭을 시킨 뒤 자동 완료라고 하지 않는다.

`TEXT_SELECTION`과 `OPEN_MANUAL`은 명시적으로 선택한 기존 수동 대안이다. 단계별 ‘열었어/했어’ 회신은 선택 사항이며 그런 보고로 실제 선택·클릭·제출을 검증하지 않는다.

## 적용과 검증

이번 후보는 기존 FIX3 원본 위에 전용 Android 실행기를 추가한다. 기존 APK가 저절로 갱신되는 방식이 아니다. 원 일반 LEFT 보호, Secure56 서명·완료와 durable 중복 방지, 기존 Gemini 전송 검토는 보존한다.

코드 검사, 원 handler 연결 검사, APK 빌드, 원 인증서 서명·설치, 실제 폰에서 세 단계 완료를 각각 구분한다. 실제 제출을 확인해도 삼성 작업·분석·영상 결과까지 완료로 올리지 않는다. 실기기 증거가 없는 현재 상태를 운영 성공으로 기록하지 않는다.

정확한 API와 상태는 [provider-contract.md](provider-contract.md), 이번 검사와 다음 지점은 [CURRENT.md](CURRENT.md)를 따른다.
