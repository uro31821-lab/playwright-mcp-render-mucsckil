# JH167 V4 — 화면 좌우 배치 정정 (2026-10-28)

## 최종 확인한 사용자 운영 기준

- **왼쪽: ChatGPT**
- **오른쪽: Chrome 또는 네이티브 Gemini**
- 기존 Secure56 인증·명령·로컬 승인·중복 방지·오른쪽 작업창 결과 재조회 유지.
- V4의 본래 목표인 단일 Android 직접 조작·Gemini 3기능 완성은 계속한다.
- 원본 V4 인계서의 "왼쪽 작업창/오른쪽 GPT"는 해당 문서 기록이지만, 사용자가 2026-10-28 다시 확인한 운영 방식과 **충돌**하므로 적용하지 않는다.

## 구분할 두 실행 경로

1. **실제 운영 JH의 왼쪽 GPT/오른쪽 Chrome·Gemini**가 V4의 고정 목표다.
2. Stage4 개발 브랜치에 있던 `LEFT_WEB_RIGHT_GPT`는 과거 격리 실험 모드로만 보존한다. V4에서는 그 모드를 기존 Chrome 작업에 자동 사용하지 않는다.
3. Gemini는 `LEFT_GPT_RIGHT_NATIVE_GEMINI`라는 별도 화면 검사로 제한한다. 원래 앱이 오른쪽이라는 사실과 초안·계정·전송 승인·응답 검증은 다른 증거다.
4. 기존 `LEGACY_LEFT_GPT_RIGHT_WORK`는 운영의 원래 일반 작업창 검증을 보존하되, 네이티브 Gemini 확인은 반드시 별도 패키지·서명된 창·현재 명령에 묶는다.

## 변경 관리와 릴리스 한계

- GitHub PR #63은 **초안 개발 후보**로 운영 적용을 하지 않았다.
- Gemini v0.5의 요청 상태·전송 정책·답변·영상 처리에서 작업 방향을 **RIGHT work / LEFT chat**으로 통일하고, 부정 테스트를 유지한다.
- 기존 Playwright/Render 운영 배포와 기존 휴대폰 APK를 변경하지 않는다.
- 전체 Android 프로젝트 빌드·원래 키 서명·실기기 설치·3기능 확인 전에는 완성으로 표시하지 않는다.
- Gemini를 통하지 않는 오른쪽 Chrome의 V4 단일 엔진 새 라우트는 기존 Secure56 포트/실기기 검증 전까지 연결하지 않는다. 원래 운영 기능은 그대로 유지한다.
