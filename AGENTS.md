# Development agent instructions

When a programming task introduces a new framework, unfamiliar feature or unresolved blocker, use [the skill discovery workflow](jh-dev-tools/find-skills/SKILL.md) before choosing an external technique. Existing verified tools and project instructions take precedence. Do not search for simple changes that are already understood. Use generic public keywords only; use no paid APIs or automatic third-party installation. Keep all existing security and release checks.
