# 메일 정리 기준

메일 정리의 목적은 가입사이트 발견과 계정 유지/정리 판단이다.

분류: 가입 / 결제 / 보안 / 탈퇴후보 / 보관 / 광고.

가입 신호: welcome, 가입완료, 회원가입, verify, 이메일 인증, activate.
보안 신호: password reset, 비밀번호 재설정, security alert, 새 로그인, new device, 2FA.
결제 신호: receipt, invoice, payment, 결제, 구독, renewal, refund.

Gmail은 실제 연결된 계정만 사용한다. Naver/Daum은 전용 connector가 없으면 인증된 브라우저 세션 또는 사용자 제공 export/메일 자료를 사용한다. 비밀번호를 요청/저장하지 않는다.

기본은 읽기 전용 분류다. 라벨/보관은 사용자의 실행 명령이 있을 때만 하고, 삭제·휴지통·수신거부는 별도 명시 요청이 필요하다.
