# 가입사이트 정리 기준

청비서는 결제 여부와 무관하게 가입 흔적을 찾는다.

## 증거
1. Sherlock: 동일 아이디 공개 계정 후보. 소유 증명 아님.
2. 개인정보 포털 본인확인 내역: 본인확인 이력. 인증만 하고 가입하지 않은 사이트가 섞일 수 있음.
3. 메일: 가입완료, 이메일인증, 계정활성화, 비밀번호재설정, 보안알림, 최근 이용, 탈퇴완료.
4. 결제: 영수증/구독은 현재 결제 판단용 보조 증거이며 가입 탐색의 필수조건이 아님.

판정은 confirmed / supported_unconfirmed / unconfirmed / not_mine / conflict로 분리한다. 광고메일만으로 가입을 확정하지 않는다.

공개 검색에는 사용자가 제공한 본인 아이디만 사용하고 이메일 주소·비밀번호·OTP·쿠키·토큰은 보내거나 저장하지 않는다.
