# 제비서 독립 시험 0.2.0 — 휴대폰에서 시작하기

이 시험은 **메뉴 읽기 → 문장 선택 → `⋯` 열기 → Gemini에 전달 → 전송 확인**만 대상으로 합니다. JH에 합치기 전의 독립 시험이며, AutoJs6에서 실행하는 JavaScript 파일 한 개입니다.

## 1. 준비할 것

- 휴대폰의 [공식 AutoJs6 v6.8.0](https://github.com/SuperMonster003/AutoJs6/releases/tag/v6.8.0). 이미 해당 실행 환경이 있으면 다시 설치할 필요가 없습니다.
- 받은 `jebiseo-independent-test.js` 한 파일. APK가 아니므로 AutoJs6에서 열거나 가져옵니다. 별도 MCP·Node.js·AI 플러그인은 사용하지 않습니다.
- AutoJs6가 화면 정보를 읽도록 Android 접근성 설정에서 허용합니다. 떠 있는 실행 버튼에 필요한 권한도 휴대폰의 안내에 따라 허용합니다. TalkBack을 켤 필요는 없습니다.
- **왼쪽 ChatGPT / 오른쪽 Gemini 앱**의 좌우 분할화면. 현재 시험본은 위·아래 분할을 지원하지 않습니다.

AutoJs6 편집기를 전체 화면으로 띄운 채 시작하면 두 앱을 확인할 수 없습니다. 분할화면을 만든 뒤 AutoJs6의 떠 있는 스크립트 실행 버튼에서 이 파일을 실행하세요.

## 2. 시험 문장

왼쪽 ChatGPT **답변 영역**에 다음 문장이 한 번만 보이도록 맞춥니다. 입력창에 붙여 넣은 글은 시험 대상으로 사용하지 않습니다. 같은 문장이 화면에 두 번 보이면 하나만 보이도록 스크롤하세요.

> 제비서 독립시험: 이 문장을 받으면 확인이라고만 답해 주세요.

오른쪽 Gemini는 입력란이 보이는 상태로 둡니다. 전달·전송 시험인 4·5번은 입력란을 비우고 이전 응답이 끝난 상태에서 시작합니다.

## 3. 시험 메뉴

| 번호 | 선택할 시험 | 어디서 멈추나 |
| --- | --- | --- |
| **1** | **화면·메뉴 읽기** | 현재 창·문장·메뉴 정보만 읽음. 누르는 동작 없음 |
| **2** | **시험 문장 선택까지만** | 정확한 선택 범위가 읽히면 종료 |
| **3** | **`⋯` 열고 Gemini 항목 확인까지만** | 메뉴를 열어 Gemini 항목을 읽으면 종료. 해당 항목은 누르지 않음 |
| **4** | **문장 선택부터 Gemini에 전달** | Gemini 입력란에 같은 문장이 들어왔는지 확인 |
| **5** | **문장 선택부터 Gemini 전송까지** | 전송 버튼을 한 번 누르고 새 제출 증거 확인 |
| **6** | **최근 결과 보기·복사** | 저장된 결과를 다시 보여줌. 화면 조회·조작 없음 |

**지금은 1번부터 시작하세요.** 보통 화면에 선택 메뉴가 안 열려 있으면 `⋯`와 Gemini 항목이 읽히지 않는 것이 정상입니다. 열린 메뉴 자체를 읽고 싶으면 1번을 선택한 뒤 준비 시간 10초 동안 직접 문장을 선택하고 메뉴를 열어 두면 됩니다. 이 시험은 그때의 화면을 한 번 읽습니다.

2~5번은 각각 문장 선택 단계부터 시작하는 별도 시험입니다. 앞선 번호의 다음 동작만 이어서 실행하는 기능은 아닙니다. 결과를 먼저 확인하고 다음 범위를 고르세요.

**4번도 문장을 Gemini에 전달합니다.** 휴대폰에 표시되는 메뉴의 동작에 따라 곧바로 질문이 전송될 수 있습니다. 이때 시험본은 추가 전송을 하지 않고 `MENU_MAY_HAVE_SUBMITTED`로 멈춥니다. 4번 실행 뒤 5번을 곧바로 누르지 말고 먼저 결과를 확인하세요.

## 4. 결과를 이 대화에 가져오기

1. 시험이 끝나면 한글 결과 창을 확인합니다.
2. 다음 화면에서 **결과 복사 — 이 대화에 붙여넣기**를 누릅니다.
3. 이 대화 입력창에 붙여넣어 보냅니다.

복사가 안 되면 결과 화면을 캡처해도 됩니다. 창을 닫았으면 스크립트를 다시 열어 **6번 최근 결과 보기·복사**를 고르세요.

결과에는 확인한 항목, 실제로 읽힌 메뉴 이름, 막힌 단계와 코드가 들어 있습니다. 대화 본문·Gemini 초안 전체는 내보내지 않습니다. `probe_ok`는 읽기 점검 결과이며 전달·전송 성공을 뜻하지 않습니다.

## 5. 멈춤·미확인 결과

- 실행 안내에 볼륨 아래 중지가 표시되면 **볼륨 아래 버튼**으로 중지할 수 있습니다. 해당 등록이 안 된 기기는 안내된 **AutoJs6 중지 버튼**을 사용합니다.
- `completion_unknown`, `MENU_MAY_HAVE_SUBMITTED`, `PREVIOUS_ATTEMPT_UNRESOLVED`가 나오면 결과를 먼저 가져오세요. 이전 시도의 결과가 불명확해 새 전달·전송을 막은 상태입니다.
- 1번 조회나 앱 재시작은 이전 미확인 전송 기록을 해제하지 않습니다. 차단 결과에서 원래 시도의 ID·단계·상태를 확인할 수 있습니다.

## 검증 범위

검사 결과와 실행 파일 해시는 `verification.json`에 기록합니다. 오프라인 검사는 제어 순서와 잘못된 클릭 차단을 확인한 것입니다. **실제 AutoJs6 실행·주인님 휴대폰의 메뉴 노출·분할화면 동작은 이번 실폰 시험에서 확인할 항목입니다.**
