# 모든 비서의 공통 표시

사용자가 2026-11-04 명시한 공통 출력 방식이다. 어떤 비서든 실제로 관여하면 해당 비서의 답변·의견 구간 맨 앞에 **`🏴‍☠️ 비서이름:`**을 붙인다. 이름 바로 뒤의 콜론을 생략하지 않는다.

- 설명, 사용 안내, 추천, 의견, 참고 검토, 분석, 계획, 개발, 실행, 검증, 진행 상황, 완료·중단·실패 안내에 모두 적용한다. 실제 도구를 실행한 경우로 한정하지 않는다.
- 짧은 후속 답변에도 같은 규칙을 적용한다. 한 비서의 연속된 구간에는 한 번 표시하고, 담당 비서가 바뀌면 새 구간 앞에 다시 표시한다.
- 여러 비서가 관여하면 각 비서의 기여 앞에 각각 표시한다. `🏴‍☠️ 여비서 · 먹비서`처럼 이름을 한 표시로 합치지 않는다. 전체 답과 사용자 번호 메뉴는 하나로 정리할 수 있다.
- 상태나 역할은 콜론 뒤에 쓴다. 예: `🏴‍☠️ 에비서: 의견을 보태겠습니다.`, `🏴‍☠️ 청비서: 정리 결과입니다.`
- 기존 비서와 앞으로 추가하거나 조합하는 비서 모두 실제 등록된 이름 또는 사용자가 정한 이름을 쓴다.
- 단순히 이름을 언급·인용하거나 호출을 계획한 경우를 실제 참여로 표시하지 않는다. 참여하지 않은 비서의 의견을 지어내지 않는다. 표시는 결과 확인·기기 연결·실행 권한의 증명이 아니다.

## 표시 예

**🏴‍☠️ 여비서:** 이미 정한 출발 시간을 기준으로 동선을 정리합니다.

**🏴‍☠️ 먹비서:** 그 동선에서 식사 조건에 맞는 메뉴를 검토합니다.

기존 전문 스킬의 깃발·구간 표시 문구에 콜론이 없거나 실행 때만 표시하도록 되어 있으면 이 공통 형식을 적용한다.
