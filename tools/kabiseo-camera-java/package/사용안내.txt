카비서 v0.22 FIX2 — PowerShell을 사용하지 않는 촬영 경로 점검

이전 FIX1 결과의 Restricted + UnauthorizedAccess에 맞춘 별도 Java 구현입니다. 기존 JH 제작에 쓰던 Java/JDK와 ADB만 찾습니다. 새 프로그램 설치, 보안 정책 변경, 인터넷 다운로드, PowerShell 호출은 없습니다. 기존 도구가 없으면 이유를 RESULT.txt에 남기고 중단합니다.

1. 기존 JH 작업 Windows PC에 휴대폰을 USB로 연결합니다.
2. ZIP 전체를 새 폴더에 압축 해제하고 실행.cmd를 더블클릭합니다.
3. 안내가 나오면 휴대폰 GPT에서 사진 찍기 화면만 열고 PC에서 Enter를 누릅니다. 사진을 찍거나 확대하지 않습니다.
4. 같은 폴더에 생긴 RESULT.txt만 올려 주세요.

기존 승인 연결이 없거나 두 대 이상이면 임의 연결하지 않습니다. 사용자 PC/폰에서 보안 제품이 차단하면 강제 허용하거나 보안을 해제하지 마세요.

기존 adb.exe로 기기 목록과 현재 화면/카메라 사용 앱만 읽습니다. 원본 진단 출력은 메모리에서만 처리합니다. 사진·화면 캡처·대화 본문·기기 일련번호·원본 로그는 저장/외부전송하지 않습니다. 알려진 앱 외에는 이름을 가립니다. 결과요약과 이전 요약만 logs에 남습니다.

이 파일은 촬영경로 확인용이며 카비서 완성 앱이 아닙니다. 카메라 사용 앱 확인만으로 GPT의 배율/노출 제어나 원상복원이 검증되지 않습니다. 앱 설치·삭제·권한 변경·촬영·화면 클릭·배율 변경·카메라 종료는 하지 않습니다.
