카비서 촬영 경로 점검 v0.22

목적: GPT의 '사진 찍기'가 GPT 내부 촬영인지 다른 카메라 앱에 맡기는지 실제 앱 식별값으로 확인합니다. 자동 촬영/배율/노출 제어 앱이 아닙니다.

1. 기존 JH 작업에 쓰던 Windows PC에 휴대폰을 USB로 연결합니다.
2. 이 ZIP 전체를 압축 해제하고 실행.cmd를 더블클릭합니다.
3. 안내가 나오면 휴대폰 GPT에서 사진 찍기 화면만 열고, PC에서 Enter를 누릅니다. 촬영하거나 확대하지 않습니다.
4. 같은 폴더에 생성되는 RESULT.txt만 이 대화에 올립니다.

기존 Android SDK의 adb.exe를 사용합니다. 새 프로그램을 다운로드/설치하거나 adb pair/connect/root를 실행하지 않습니다. 기기가 여러 대이거나 기존 승인 연결이 없으면 중단합니다. Windows 보안 정책이 스크립트를 막으면 정책을 끄지 말고 오류를 알려 주세요.

실행하는 기기 명령은 현재 Activity 및 camera service의 dumpsys 읽기뿐입니다. 사진·스크린샷·대화 본문·전체 진단 로그·기기 일련번호는 저장하거나 외부 전송하지 않습니다. 원본 dumpsys는 메모리에서만 읽고 허용된 앱 식별값과 분류 결과만 RESULT.txt로 저장합니다. 다른 앱의 이름은 OTHER_REDACTED로 처리합니다. 실행 횟수별 요약은 logs 폴더에 보존합니다.

현재 카메라를 쓰는 앱이 확인돼도 자동 설정이나 GPT 내부 카메라 교체가 가능하다고 확정하지 않습니다. 제조사 출력이 다르거나 관찰 중 창이 바뀌면 UNKNOWN/BLOCKED를 유지합니다. 과거 카메라 사용 이력은 현재 사용 근거로 쓰지 않습니다.

앱 설치/삭제, 권한 변경, 화면 클릭, 촬영, 배율/노출 변경, 카메라 종료, 로그 업로드는 수행하지 않습니다. 별도 관리자 실행 불필요. 한 번 점검이며 예약/상시 감시 기능은 없습니다.
