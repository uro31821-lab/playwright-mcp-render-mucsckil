카비서 v0.22 FIX1 — PC 시작 오류 확인용

이 파일은 카메라 기능 수정본이나 설치본이 아닙니다. 앞선 RESULT.txt에 상세 원인이 남지 않은 문제를 보완해 PC의 PowerShell 시작/스크립트 로딩 상태만 확인합니다.

전체 압축을 푼 뒤 실행.cmd를 더블클릭하고, 같은 폴더에 생성된 RESULT.txt만 올려주세요. 휴대폰 USB 연결, GPT 촬영 화면 열기, 촬영·확대 조작은 필요 없습니다. 이전 실행 폴더에 덮어쓰지 않아도 됩니다.

확인 항목: PowerShell 버전과 실행 정책 이름, 파일 존재 여부·검증값, 인터넷 다운로드 표시 여부, 스크립트 구문 오류 식별자, 정상 -File 로딩의 종료코드와 오류 종류. 원본 probe.ps1은 -LibraryOnly로만 불러오며 Main 및 ADB는 실행하지 않습니다. 사용자 이름·경로·원본 오류 내용·기기정보·사진·대화 내용은 결과에 넣지 않습니다.

실행 정책·다운로드 표시·보안설정을 변경하지 않습니다. 스크립트 차단을 우회하거나 관리자 권한을 요청하지 않습니다. 정책 차단이 확인되면 BLOCKED로 그대로 기록합니다. 이때 차단을 해제하려고 보안 옵션을 끄지 마세요.

STARTUP_ONLY_PASS는 스크립트 정의를 정상 읽었다는 뜻일 뿐, 실제 카메라 조회/자동 설정/원상복원 성공이 아닙니다. 보안 제품이 실행 자체를 막으면 파일을 강제로 실행하지 말고 해당 안내를 알려주세요.
